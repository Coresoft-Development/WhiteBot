# Security Policy

## Supported Versions

WhiteBot masih dalam tahap pengembangan dan belum dirilis secara resmi.

| Version | Supported |
| ------- | --------- |
| development / main | ✅ |
| pre-release        | ⚠️ (limited) |
| released versions  | ❌ |

Catatan:
- Hanya branch **development / main** yang aktif dikembangkan.
- Versi lama atau hasil fork tidak mendapatkan update keamanan.

## Reporting a Vulnerability

Jika kamu menemukan potensi celah keamanan atau bug kritis pada WhiteBot,
harap **jangan mempublikasikannya** ke forum atau media sosial.

Silakan laporkan melalui:
- GitHub Issue (gunakan label: `security`)
- aethrasystemsfoundation@gmail.com

### Proses penanganan
- Laporan akan ditinjau dalam **waktu fleksibel** (karena project masih aktif dikembangkan)
- Jika laporan valid, perbaikan akan dilakukan sebelum rilis publik
- Jika tidak relevan, penjelasan singkat akan diberikan

Terima kasih sudah membantu menjaga WhiteBot tetap aman 🤍
